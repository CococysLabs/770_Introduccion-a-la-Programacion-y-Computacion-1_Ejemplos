## 📥 Clonar

### Clonar el repositorio completo

```bash
git clone https://github.com/CococysLabs/770_Introduccion-a-la-Programacion-y-Computacion-1_Ejemplos.git
```

### Descargar solo un ciclo específico

Si no necesitas todos los ciclos, puedes usar sparse-checkout para traer solo el que te interesa:

```bash
git clone --filter=blob:none --sparse https://github.com/CococysLabs/770_Introduccion-a-la-Programacion-y-Computacion-1_Ejemplos.git nombre-carpeta
cd nombre-carpeta
git sparse-checkout set ciclo-xxxx-xxxx-xxxx
```

Donde:

- `nombre-carpeta` es el nombre que tendrá la carpeta descargada en tu computadora.
- `ciclo-xxxx-xxxx-xxxx` es el ciclo específico que deseas descargar (por ejemplo `Ciclo-2025-Segundo-Semestre`).
